# Tag 3 — Hübsch & Hörbar

**Heute soll am Ende stehen:** Das Spiel sieht und klingt deutlich besser. Die Mechanik aus Tag 2 ist UNVERÄNDERT.

**Worauf du dich konzentrierst:**
- Bessere Farben, Hintergründe, Verläufe, Schatten
- Figuren mit mehr Charakter (Augen, Animation, Wackeln, kleine Bewegung)
- Geräusche/Sounds: per Web Audio API selbst erzeugen (kurze Bleeps, Bloops, Töne) — niemals automatisch laute Musik
- Übergänge, Partikel-Effekte (kleine Sterne, Wolken), zarte Animationen

**Was du heute NICHT tust:**
- Die Spielregel ändern oder verkomplizieren
- Punkte/Levels/Schwierigkeit einführen (das ist Tag 4)
- Externe Bilder oder Sounds einbinden — alles inline / selbst gezeichnet (CSS, SVG, Canvas)

**Wenn der Wunsch zu offen ist (z. B. "Mach es schöner"):**
- Sanfter Farbverlauf im Hintergrund passend zum Thema
- Hauptfigur bekommt eine kleine Idle-Animation (atmen, wackeln)
- Beim Erfolg: kleine Sternchen/Konfetti
- Beim Fehler: kurzes Schütteln + ein "boing"-Sound

**Wichtig:** "Erhalte die Spielregel exakt von Tag 2." Sounds müssen leise starten und einen sichtbaren Aus-Knopf haben (Lautsprecher-Symbol oben rechts).
